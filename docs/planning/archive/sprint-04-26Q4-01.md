### Key Findings / Lessons Learned

- **A measurement is not a decision.** DoD 1 asked for densities and got
  them. The slice decision needed a human read of 37 statements, which the
  sprint never sized. When the deciding step is a person's time, it should be
  a row with an owner and a date.
- **A control that can't fail proves nothing; one that can, can fail.** #82
  made the Gate A control able to fail, and it then failed DoD 2 as written.
  That is the instrument working. The bar needs restating, not the control
  re-running until it passes.
- **Every run-level defect came from running.** The shared sampling seed,
  the colliding seeds, the NCCL hang, the wrong-content tag closures and the
  toolkit-less node were all found on the box. None was visible from code
  review. The standing rule (every sprint runs something) keeps paying.
- **Serving took four tries.** R5b, R5c and R5d each failed on a different
  layer (CUDA toolkit, NCCL start-up, FlashInfer sampler); R5e passed. Record
  each attempt's failing layer in the runbook, as R5 did, so the next restore
  starts from what worked.
- **Branches that hold a pending batch's pins must not be merged.** Branches
  auto-delete on merge, so q1's pins were held on draft PRs, and q2's on a
  no-PR integration branch (`batch/q2-pins`).
- **A sim with a stronger model finds promotion defects cheaply.** The Sonnet
  team simulation (2026-11-06) found `-16`/`-17`/`-18` before any box run did.
