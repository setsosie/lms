### Key Findings / Lessons Learned

- **Finishing the committed points is not finishing the sprint.** 10/10 points
  landed on day 10, and the goal was still open at close. When the deliverable
  is a run, the run should be the row, with points, so the board cannot show
  green without it.
- **The found-work rule failed again, in a new way.** In Sprint 2, found-work
  displaced unstarted critical-path code. This time the code was done, and
  found-work displaced the *run*: three weeks of box time went to committee
  runs (all real defects, all fixed), not to Step 7.
- **A void number is worse than a missing one.** The 2026-08-19 ramification
  reading looked like a strong result (20/21 N1 at 0.9). It was the defect's
  signature. Had it been recorded, it would have picked the wrong slice.
  Before reading any density, check `stages_run` and `max_n1_confidence`.
- **Squash merges can drop code silently.** #53 and #56 each lost code in the
  squash. Main was red from #53 to #61, and no one knew, because the repo had
  never run CI. Both gaps are now closed (#60, #61).
- **Self-reported references are not evidence of reuse.** `committee_yolo_a`
  contains the project's first verified committee reuse, yet it printed
  "Reuse Rate: 0.0%" and a ratchet-failure warning. Derive references from the
  Lean source.
- **Two external results (FLT via Prove2Me; an unaccepted Navier-Stokes claim)
  each invited a reframe in one week.** ADR 0001 absorbed the first as a
  control arm. The pre-commitment exists to survive news. Get the number first.
