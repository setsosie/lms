### Key Findings / Lessons Learned

- **The cumulative-knowledge mechanism had never once worked.** `-09` found that
  `foundation.save()` only ran at a 10-generation checkpoint, so on any shorter
  run every `import LMS.Foundation` resolved to a module predating the run.
  Every reuse and ratchet figure recorded before 2026-08-10 is meaningless.
- **Running it on the box found in two days what code review had not found in
  months.** All five box-found cards (`-08` through `-13`) are defects that only
  a real execution surfaced. The lesson is not "plan better" — it is *run it
  sooner*.
- **Gate B-minus green is not a CVFN numerator.** Every verified artifact to date
  is an N0 from-scratch reimplementation of Mathlib with no `import` line. Tag
  `0013: Category` is exactly where a re-export would land. Read
  `artifacts.json`, never the run summary.
- **Scope discipline is the story of this sprint.** 17 pts added, 8 of them
  delivered, while 13 pts of originally-planned CRITICAL gate work (`-03`,
  `-04`, `-05`) sat untouched for the whole window. The added work was all
  legitimate; the failure was not defending the planned critical path against it.
- **A merged PR is not a finished task.** #30 merged a card and a verify stub for
  `-13` with no implementation. Counting it as delivered would have inflated this
  archive's velocity row by 2 pts.
- **Gate A was never run**, so the sprint's own exit criterion is unevaluated. It
  carries to Sprint 3 as a Definition-of-Done item.
